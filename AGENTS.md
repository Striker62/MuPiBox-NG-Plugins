# AI agent instructions

For all changes in this repository, read and follow [ai.md](ai.md) first, then [docs/manifest-v1.md](docs/manifest-v1.md) and [SECURITY.md](SECURITY.md).

The MuPiBox-NG core is private. Never copy core code or protected game assets into this public SDK.


Community-App design references (for coding agents): `ai.md` describes
the distinction between package-owned HTML/CSS wallpaper
(`display.background`) and native Home tile artwork (`manifest.cover`).
Read `docs/manifest-v1.md` and `GETTING_STARTED.en.md` before editing
examples, schema, validation or app UIs. SVG icons are not native Qt
raster covers. Keep packaged art separate from SMB shared-assets.
