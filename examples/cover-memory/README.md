# Cover-Memory

Eigenständig entwickelte Community-App für klassische Bildpaare (Formen, Tiere,
Zahlen, gemischt) und lokale Mediencover. 4, 6 oder 8 Paare, Züge, Zeit,
Neu mischen und automatischer Offline-Rückfall. Eigene Cover benötigen einen
Host mit der neuen, separat widerrufbaren Berechtigung cover-art; keine
Netzwerkverbindung oder Dateisystemberechtigung. Bilder verbleiben im RAM.
Touch-Bedienung, Deutsch/Englisch. Keine privaten Core-Assets übernommen.

Build: python3 tools/build_cover_memory.py
