# MuPi Malbuch

Eigenständige Offline-Web-App: freies Zeichnen, eigene Vektormotive, zehn Farben,
drei Stiftgrößen, Radierer, Undo und Neustart. Eigene lokale Ausmalbilder bleiben
über die optionale, separat widerrufbare Berechtigung coloring-pages verfügbar.
Die bisherigen Samba-Ausmalbilder bleiben unverändert. Keine privaten Core-
Grafiken oder Quelltexte kopiert. Kein Netzwerk und keine Bildspeicherung.
Build: python3 tools/build_malbuch.py
